# QR Code Generator

Приложение для генерации QR-кодов

## Возможности

- Генерация QR-кодов из текста или URL
- Настройка размера (100-1000 px)
- Сохранение в PNG
- Кроссплатформенность

## Установка

```bash
git clone https://github.com/anixvoid/qr-code-generator
cd qr-code-generator
pip install -r requirements.txt
python src/main.py
```


## Зависимости
- Python 3.8+
- PyQt6
- qrcode[pil]
- Pillow

## Использование:
- Введите текст
- Выберите размер
- Нажмите "Сгенерировать"
- Сохраните результат
